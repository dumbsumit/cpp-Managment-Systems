# C++ Management System

A comprehensive **C++ console-based Management System** that combines multiple real-world management modules into a single application.
This project demonstrates strong understanding of **Object-Oriented Programming (OOP)**, **File Handling**, **Data Management**, and **Menu-Driven Application Design** using C++.

---

## 🚀 Features

The project contains multiple independent management systems:

* 🏥 Hospital Management System
* 🏨 Hostel Management System
* 📚 Library Management System
* 📦 Inventory Management System
* 👨‍💼 Employee Management System
* 🍽 Restaurant Management System
* 🧾 Bill Management System
* 🏫 School Management System

---

  * Object-Oriented Programming (OOP)

# 💻 How to Run the Project

## Step 1: Clone the Repository

```bash
git clone https://github.com/dumbsumit/Cpp-Management-System.git
```

---

## Step 2: Open Project

Open the project folder in:

* VS Code
* CodeBlocks
* Dev C++
* Visual Studio

---

## Step 3: Compile the Code

Using g++ compiler:

```bash
g++ filename.cpp -o output
```

Example:

```bash
g++ hospital.cpp -o hospital
```

---

## Step 4: Run the Executable

### Windows

```bash
output.exe
```

### Linux / Mac

```bash
./output
```
